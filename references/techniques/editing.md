# 技法辞典：編集とトランジション（30種）

索引は [index.md](index.md)。1回の生成で複数ショットを出すとき、または分割生成したショットを後でつなぐ前提で使う。連続性の作り方は [multi-shot-continuity.md](../multi-shot-continuity.md)、ショットラベルと秒数の制約は [prompt-syntax.md](../prompt-syntax.md) に従う。

- Kling公式が1回の生成の中で使える編集の語として例示するのは shot-reverse-shot（切り返し）、cross-cutting（クロスカッティング）、voice-over（ボイスオーバー）、`Cut to ...`（次のショットへ切り替える）など（**【公式】**、3.0時点）。それ以外の用語が1回の生成の中で効くかは**【未確認】**なので、切り替えの前後で何が見えるかを具体的に書く。
- ディゾルブ、ワイプ、アイリスなどの光学的なつなぎは、生成後に編集ソフトで付けるほうが確実なことが多い。
- Kling 4.0 はスマート絵コンテが常に有効で、カット割りをモデルに任せることもできる。カットの数と位置を決めたいときは区間ごとに書き、使わないトランジションも明記する（[prompt-syntax.md](../prompt-syntax.md) §4）。

表の見方：「技法」は英語の呼び名、「記述例」はプロンプトに書く型。被写体・場所・秒数は依頼に合わせて書き換え、例をそのまま貼らない。

## 1. 形や動きでつなぐ

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Match Cut | マッチカット | 形・動き・構図が似た2つのショットを直接つなぐ。両方のショットを同じ言葉で書く | `0～4秒：回るコーヒーカップの丸い縁を真上から。4～8秒：Match cut。同じ位置と大きさで、回る観覧車を真下から。` |
| Graphic Match | グラフィックマッチ | 輪郭と画面上の位置を一致させてつなぐ。丸には丸、水平線には水平線 | `Graphic match。前のショットの満月と同じ位置・同じ大きさで、次のショットの白い皿を映す。` |
| Match on Action | アクションつなぎ | 動作の途中でカットし、次のショットで同じ動作の続きから見せる | `Match on action。Shot 1：ドアノブを回し始める手元の寄り。Shot 2：同じ動作の続きで、扉を押し開ける人物を廊下側から。` |
| Match Motion | モーションマッチ | 動きの方向と速さを合わせて、別の場所や世界へつなぐ | `Match motion。回転しながら跳ぶダンサーの動きの途中で、同じ向き・同じ速さで回るフィギュアスケーターへつながる。` |
| Invisible Cut | 見えないカット | 横切る人物、暗い壁、ホイップパンのブレなどにつなぎ目を隠し、1カットに見せる | `Hidden cut。カメラの前を黒い柱が横切って画面が暗くなった瞬間に、別の場所にいる同じ人物へ切り替わる。` |
| Set Transition | セットトランジション | カットせずに、周囲の空間そのものが別の場所へ変わる | `In-camera set transition。人物が歩き続けるうちに背後の壁が横へ動き、寝室が駅のホームへ変わる。カットなし。` |
| Motivated Cut | きっかけのあるカット | 動作の頂点、音の頭、手前を横切る物、靴先の動きなど、切る理由のある瞬間でカットする。Kling 4.0 公式の作例の書き方 | `少女が顔を上げる動作の頂点に合わせてハードカットする。リコーダーの音はカットより0.1秒早く入れる。` |
| Eyeline Match | 視線つなぎ／見た目のカット | 人物が見る → 見ている物、の順につなぐ。視線の方向と次のショットの向きを合わせる | `Shot 1：人物は画面右上を見上げる。Shot 2：その視線の先、右上から見下ろす角度で、窓辺に止まる鳥を映す。` |

## 2. 不連続を見せる

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Jump Cut | ジャンプカット | 同じ画角のまま時間を飛ばし、不連続をあえて見せる | `Jump cuts。同じ構図のまま、ソファの人物の姿勢と位置が数回飛び、時間の経過を見せる。` |
| Axial Cut | アキシャルカット | 同じ軸の上で一段ずつ急に寄る（または引く）。驚き、強調 | `Axial cut。同じ正面の軸のまま、全身から腰上、顔の寄りへと2段階で急に寄る。` |
| Smash Cut | スマッシュカット | 静から動、静寂から轟音へ、落差の大きいショットを前触れなく直接つなぐ | `Smash cut。静かな寝室で目を閉じる人物から、前触れなく轟音の工事現場へ切り替わる。` |
| Crash Cut | クラッシュカット | 出来事の真っただ中から唐突に始まるカット | `Crash cut。穏やかな食卓から、すでに全力で走っている人物の息づかいの寄りへ唐突に切り替わる。` |
| Flash Cut | フラッシュカット | 数フレームだけ別の映像を差し込む。記憶、予感、トラウマ | `Flash cut。見つめる人物の顔の途中に、赤い傘の映像が一瞬だけ差し込まれてすぐ戻る。` |

## 3. 光学的なつなぎ

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Transitions | トランジション（総称） | つなぎ方そのものを見せ場として設計する。前後の画を対にして考える | `ショットの境目に、つなぎ方を名前で書き、前後で何が見えるかを添える（Cut to、match cut、whip pan）。` |
| Dissolve | ディゾルブ／オーバーラップ／クロスフェード | 前の画が消えながら次の画が現れる。時間の経過、回想 | `Dissolve。夕暮れの校舎が薄れながら、同じ校舎の朝の風景が重なって現れる。` |
| Fade In / Fade Out | フェードイン／フェードアウト（溶明・溶暗） | 黒（または白や色）から現れる、黒へ消える。章の区切り | `Fade out to black。語り終えた人物の姿が、ゆっくり黒へ消える。` |
| Wipe | ワイプ | 境界線が画面を横切り、次のショットに置き換える | `Horizontal wipe。縦の境界線が画面を左から右へ横切り、砂漠のショットが雪原のショットに置き換わる。` |
| Iris | アイリス | 円形に開く（アイリスイン）・閉じる（アイリスアウト）。無声映画風、注目の一点 | `Iris out。画面が円形に閉じていき、最後に笑う人物の顔だけが丸く残って暗転する。` |

## 4. 構成とリズム

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Continuity Editing | 連続性の編集 | 位置関係・視線・動きの方向・光をショット間でそろえ、カットを意識させずに見せる。物語映画の基本 | `3ショット、ハードカットでつなぐ。全ショットで、Aは画面左で右向き、Bは画面右で左向き、光は画面左の窓から。` |
| Shot-Reverse-Shot | 切り返し | 向かい合う2人を、交互に相手側から撮って会話を見せる。Kling公式が例示する編集の語（3.0時点） | `Shot-reverse-shot。0～4秒：Aの肩越しにBの顔。4～8秒：Bの肩越しにAの顔。2人の左右の位置は入れ替えない。` |
| Cross-Cutting | クロスカッティング／カットバック／パラレル編集 | 別の場所で同時に起きる2つの出来事を交互に見せる | `Cross-cutting。0～5秒：夜道を急ぐ人物。5～10秒：同じ時刻、家で時計を見つめる家族。10～15秒：再び夜道の人物。` |
| Montage | モンタージュ | 短いショットを積み重ね、時間の経過や意味を作る | `Training montage。練習する人物の短いショットが続き、汗の量と上達が少しずつ増えていく。` |
| Intellectual Montage | 意味のモンタージュ／クレショフ効果 | 無関係な2つの画を並べ、観客の頭の中で第3の意味を生む。中立の表情＋見ている物で感情が変わって見える | `Shot 1：無表情でこちらを見る男性の顔。Shot 2：湯気の立つスープの皿。Shot 3：同じ無表情の顔。` |
| Metric Montage | 等間隔のカット | 画の内容に関係なく、一定の長さでショットを切り替える。機械的な緊張、拍に合わせた映像 | `12ショット、すべて1秒ずつ等間隔のハードカット。工場の機械の部分を次々に見せる。` |
| Rhythmic Montage | 動きのリズムで切るカット | 画面の中の動きや速さに合わせてショットの長さを変える。動きが速いほど短く | `走る人物の歩幅に合わせてカットし、速度が上がるにつれてショットを短くしていく。` |
| Quick Cuts | クイックカット | 短いショットをテンポよく連ね、切り替えを徐々に速める。サイズと角度を毎回変える | `Quick cuts。短いショットが続き、手元、横顔、足元、全身とサイズと角度を毎回変える。` |
| Fragments | フラグメント | 出来事を部分（近づく物、体の一部、反応、結果）に分けて見せる | `Fragmented action。迫るヘッドライト、ハンドルを切る手、見開いた目、道路に残るタイヤ痕の順に見せる。` |
| Split Screen | 分割画面 | 画面を分割し、別の場面を同時に見せる。電話の両側、比較 | `Split screen, vertical divide。画面左に朝の台所の母、右に同じ時刻の教室の娘を同時に映す。` |
| Match Split | マッチスプリット | 分割した両側で線や動きがつながり、1つの形が2つの世界にまたがる | `Match split screen。左右に分割した画面で、左の海の水平線と右の砂漠の地平線が同じ高さでつながる。` |
| J-Cut / L-Cut (Visual Setup) | Jカット／Lカット | 次の音が映像より先に始まる（J）、映像が変わっても前の音が続く（L）。音をどのショットに置くかで書く | `L-cut。前のショットのセリフが続いたまま、映像だけが聞いている相手の表情へ切り替わる。` |
