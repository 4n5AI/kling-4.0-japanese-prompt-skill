# 技法辞典：物語構成（35種）

索引は [index.md](index.md)。Kling 4.0 は1回の生成で最長30秒を作れ、スマート絵コンテがショットを分けてテンポを組み立てる（**【公式】**）。短い尺で物語を成立させるには、**何を、何秒目に、どの順で見せるか**を決めてから区間に割り付ける。区間の書き方は [prompt-syntax.md](../prompt-syntax.md) の §4、ショットのつなぎは [editing.md](editing.md)、音で場面をつなぐ技法は [sound.md](sound.md) を参照する。

- **構成の名前をプロンプトに書いても、構成にはならない。** 「起承転結で」「伏線を張って」ではなく、各区間で画面に何が起きるかを書く。記述例は、構成を区間の内容へ書き下ろした型。
- **1区間に1つの出来事。** 短い尺に出来事を詰め込みすぎると、どれも読み取れない。セリフの量も区間の長さに収める（[SKILL.md](../../SKILL.md)）。
- **感情の山の位置を決める。** Kling 4.0 公式の作例は、感情の流れを `L1 好奇心 → L3 驚き → L4 恐怖 → L5 … → L1 …` のように強さの段階で書いている（**【公式】**。[prompt-syntax.md](../prompt-syntax.md) §3）。

表の見方：「技法」は英語の呼び名、「記述例」はプロンプトに書く型。人物・場所・秒数は依頼に合わせて書き換え、例をそのまま貼らない。

---

## 1. 冒頭のつかみ

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Hook | フック／つかみ | 最初の1〜2秒で、続きを見たくなる出来事や違和感を見せる。SNSの短尺動画、広告 | `0～2秒：机の上のコーヒーカップが、誰も触れていないのにゆっくり宙に浮き上がる。` |
| In Medias Res | 途中から始める | 出来事の最中から始め、説明を後に回す。Kling 4.0 公式の作例も「各ショットを動作の途中から始め、何も起きない導入を作らない」と書く | `0秒の時点で、人物はすでに全力で走っており、息を切らして背後を振り返る。` |
| Cold Open | アバン／コールドオープン | タイトルやロゴの前に、本編の一場面を短く見せる | `0～4秒：暗い倉庫で懐中電灯の光が揺れ、何かが倒れる音。4秒目に黒地へハードカットし、中央に白い文字でタイトル「…」を表示する。` |
| Visual Question | 謎を見せる | 答えを見せずに「これは何か」を見せ、最後に答えを出す | `0～5秒：真っ白な粉が舞う手元の超クローズアップだけを見せる。12～15秒：カメラが引き、パン職人が生地をこねている全体が見える。` |

## 2. 構成の型

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Kishōtenketsu | 起承転結 | 状況の提示 → 展開 → 意外な転換 → 結末の4段。15秒なら各3〜4秒が目安 | `0～4秒（起）：雨の朝、少女が傘を持たずに玄関に立つ。4～8秒（承）：走り出し、髪が濡れていく。8～12秒（転）：角を曲がると、同級生が傘を差し出して待っている。12～15秒（結）：2人で1つの傘に入って歩き出す。` |
| Jo-Ha-Kyū | 序破急 | ゆっくり始まり、崩れ、急速に終わるテンポの型。間を生かした和の演出、アクション | `0～8秒（序）：静止した道場で、剣士が目を閉じて構える。8～12秒（破）：風で障子が揺れ、剣士が目を開く。12～15秒（急）：一瞬で踏み込み、斬り抜けて静止する。` |
| Three-Act Structure | 三幕構成 | 設定 → 対立 → 解決。30秒なら 8秒・14秒・8秒程度に割る | `0～8秒：新人の料理人が厨房に立つ。8～22秒：注文が殺到し、鍋が焦げ、料理長ににらまれる。22～30秒：最後の皿を完璧に仕上げ、料理長が小さくうなずく。` |
| Inciting Incident | きっかけの出来事 | 日常を崩し、物語を動かす出来事を早い区間に置く | `3秒目、静かな図書館で、本の間から1枚の古い地図が床に落ちる。` |
| Problem–Solution | 課題→解決 | 困りごとを見せてから、商品や行動で解決する。広告の基本型 | `0～5秒：絡まったイヤホンのコードに苛立つ手元。5～10秒：@画像1のワイヤレスイヤホンのケースを開ける。10～15秒：人物が軽やかに歩き出し、音楽に合わせて首を揺らす。` |
| Before / After | ビフォーアフター | 変化の前と後を対比する。キーフレームの始終フレームと相性がよい（**【公式】**の活用シーン） | `@画像1（散らかった部屋）を開始フレーム、@画像2（片付いた部屋）を終了フレームとし、その間に人物が手際よく片付けていく過程を描く。` |
| Escalation | エスカレーション | 同じ出来事を、だんだん大きく・速く・多くしていく | `ドミノが1つ倒れ、続いて10個、最後は部屋全体を埋め尽くす数千個が連鎖して倒れていく。` |
| Rule of Three | 3回の反復／三段オチ | 2回同じことを見せ、3回目で外す。コメディ、記憶に残る広告 | `1回目と2回目、猫は棚の上へ軽々と跳び乗る。3回目、勢い余って棚を飛び越え、向こう側の洗濯かごへ落ちる。` |
| Countdown | カウントダウン | 残り時間や数を減らしていき、0の瞬間に山を置く | `画面右上の時計の秒針が10から0へ進み、0の瞬間にすべての照明が一斉に点く。` |
| Loop Structure | ループ構成 | 最後の画面が最初の画面につながり、繰り返し再生しても切れ目がない。SNSの短尺動画 | `最後の1秒で、人物が最初と同じ位置・同じ姿勢でドアを開ける状態に戻り、0秒の画面と一致させる。` |
| Character Arc | 人物の変化 | 短い尺でも、表情や姿勢で人物の変化を見せる | `冒頭は肩を落として下を向いている少年が、最後には胸を張り、まっすぐ前を見て歩く。` |

- 尺ごとの割り付けの目安は下の「尺別の割り付け」を参照。秒数はこのSkillの目安（**【未確認】**）で、Kling の公式資料の規定ではない。

## 3. 伏線と驚き

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Plant and Payoff | 伏線と回収 | 前半にさりげなく見せたものが、後半で意味を持つ | `2秒目、机の端に置かれた赤いお守りを一瞬だけ映す。12秒目、転びかけた人物が、そのお守りを握りしめて踏みとどまる。` |
| Foreshadowing | 予兆 | これから起きることを、先に小さく暗示する | `乾杯の場面で、グラスの水面だけがかすかに波打ち続けている。` |
| Reveal | 正体の開示／種明かし | 隠していたものを、カメラの動きや遮蔽の解除で見せる。Kling 4.0 公式の作例は、車内から引いて「カメラマンの正体」を明かす | `カメラが運転席の窓を抜けて後方へ引き、並走するバイクの上でカメラを担ぐ撮影者の全身が見える。` |
| Twist | どんでん返し | 最後に前提をひっくり返す。オチ、広告の意外性 | `最後の3秒でカメラが引くと、緊迫した宇宙船の操縦席は、子ども部屋の段ボールで作った工作だったと分かる。` |
| Red Herring | ミスリード | 観客の注意を、本当の答えとは別のものへ誘導する | `怪しげな黒いコートの男に何度も寄る。最後に、袋を持ち去ったのは隣で笑っていた老婦人だったと分かる。` |
| Dramatic Irony | 観客だけが知っている | 人物が気づいていない危険や事実を、観客にだけ見せる | `人物は笑顔で電話をしているが、画面の手前では、テーブルの端からケーキの皿が少しずつずり落ちていく。` |
| MacGuffin | マクガフィン | 中身は重要ではないが、全員が追い求める物。追跡劇の推進力 | `登場人物全員が、淡く光る小さな金属の箱を奪い合う。箱の中身は最後まで見せない。` |
| Punchline | オチ | 最後の一瞬で笑いや納得を落とす。短尺、コメディ | `最後の1秒、真剣な顔で決めポーズをした人物の頭に、上から鳩が1羽とまる。` |
| Cliffhanger | 引き／クリフハンガー | 結末を見せずに、最も緊張した瞬間で終える。連続投稿、続編への誘導 | `扉の向こうから光が漏れ、人物が取っ手に手をかけた瞬間、画面が黒に切り替わる。` |

## 4. 時間の扱い

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Flashback | 回想 | 現在から過去へ移る。色や質感を変えて、過去だと分かるようにする | `8～12秒：老人が古い写真を見つめた後、同じ公園で遊ぶ子どもの頃の本人へハードカットする。過去の場面だけ、色あせた暖色と粗いフィルムグレイン。` |
| Flashforward | 未来の挿入 | これから起きる場面を先に見せ、そこへ至る過程に注目させる | `冒頭2秒だけ、表彰台で泣き笑いする選手を見せ、その後、早朝の誰もいない練習場へハードカットする。` |
| Time Compression | 時間の圧縮 | 長い工程や時間経過を、カットで省略して見せる。Kling 4.0 公式の鍛冶の作例の書き方 | `6ショット、ハードカットでつなぐ。省略はカットで行い、各動作は自然な重さと速さのまま見せる。` |
| Parallel Storylines | 並行する2つの物語 | 別々の場所の出来事を交互に見せ、最後に交わらせる | `駅へ走る男性と、ホームで待つ女性を交互に見せる。最後のショットで2人が同じ画面に入る。` |
| Frame Narrative | 枠物語／劇中劇 | 外側の場面の中で、別の物語が語られる・映される | `祖母が絵本を読み聞かせると、絵本のページの中の絵が動き出し、その世界へカメラが入っていく。` |
| Real Time | リアルタイム | 省略をせず、出来事の時間と映像の時間を一致させる。緊張、ワンカット | `15秒のワンカット。時間の省略や速度の変化はなく、出来事は実時間で進む。` |

## 5. 語り手と意味

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Show, Don't Tell | 説明せずに見せる | 感情や状況をセリフで説明せず、行動と物で見せる。Kling 4.0 の「抽象語を具体的な描写に置き換える」原則と同じ考え方 | `「寂しい」と言わせず、2人分の食器のうち1つだけを洗い、もう1つを棚に戻す手元を見せる。` |
| Voiceover Narration | ナレーションで語る | 画面の外の語りで、映像に情報や皮肉を重ねる | `ナレーション（落ち着いた男性の声、日本語）：「…」。画面の人物の口は動かない。` |
| Direct Address | 観客への語りかけ | 人物がカメラを見て観客に話しかける。商品紹介、SNS（辞典の Fourth Wall） | `人物はレンズをまっすぐ見つめ、観客に話しかけるように明るく言う。「…」` |
| Motif | モチーフの反復 | 同じ物や形を何度も登場させ、意味を積み重ねる | `赤い風船が、冒頭の窓辺、中盤の街角、最後の空に、それぞれ一度ずつ現れる。` |
| Symbolism | 象徴 | 抽象的な意味を、具体的な物に託す | `別れの場面で、2人の間のテーブルに置かれた砂時計の砂が、最後の一粒まで落ちる。` |

- ナレーションのリップシンクの注意は [sound.md](sound.md) を参照。観客への語りかけのショットの書き方は [framing-angles.md](framing-angles.md) の Fourth Wall。

## 尺別の割り付けの目安

区間の数を尺に合わせて決める。下の表はこのSkillの目安で、依頼の内容に合わせて変える（**【未確認】**）。

| 尺 | 出来事の数 | 割り付けの例 |
|---|---|---|
| 5秒 | 1つ | フック1つ、またはオチ1つだけ。`0～5秒：` の1区間で、始まりと終わりの状態を書く |
| 10秒 | 2〜3つ | `0～3秒：つかみ` → `3～8秒：展開` → `8～10秒：結末` |
| 15秒 | 3〜4つ | 起承転結を各3〜4秒。または `0～2秒：フック` → `2～11秒：展開` → `11～15秒：オチ` |
| 30秒 | 4〜6つ | 三幕構成を 8秒・14秒・8秒程度。ショットを分けるなら、ショット数とカットの位置を明記する |

- SNSの縦型短尺では、最初の1〜2秒に最も強い画面を置き、説明は後に回すのが一般的な考え方。
- 広告で商品を見せる位置（冒頭・中盤・最後）と、ロゴや文字を表示する秒数を、区間の中で決めておく（画面の文字の書き方は [prompt-syntax.md](../prompt-syntax.md) §9）。

## 確度

- 各技法の説明と記述例は、一般的な脚本・映像編集の知識を基に、このリポジトリで書き下ろしたもの。Kling 4.0 公式の作例に由来する書き方（動作の途中から始める、カットによる時間の圧縮、正体の開示、感情の段階）は、その旨を記した。
- 構成の名前や秒数の割り付けが Kling 4.0 の結果にどう効くかは検証していない（**【未確認】**）。ユーザーへ断定して伝えず、生成結果を見て区間の内容を調整する。
