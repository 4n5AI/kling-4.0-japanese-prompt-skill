# 技法辞典：ジャンルと映像様式（62種）

索引は [index.md](index.md)。**ジャンル名だけで済ませず、光・色・レンズ・カメラ・美術の要素に分解して書く。** 特定の監督名や作品名に頼ると再現性が低く、特定作品の複製を狙う書き方にもなるため、要素で書く。ジャンル名は冒頭の1語にとどめ、続けて要素を並べる。

表の見方：「技法」は英語の呼び名、「記述例」はプロンプトに書く型。被写体・場所は依頼に合わせて書き換え、例をそのまま貼らない。

## 2. 映画運動と地域の様式

| Neo-Western | ネオ・ウエスタン | 現代の西部。ピックアップトラック、ガソリンスタンド、乾いた平原の強い日差し、寡黙な人物 | `Neo-western。乾いた平原の一本道、砂埃をかぶったピックアップトラック、寂れたガソリンスタンドの前に立つカウボーイハットの男、硬い午後の日差し。` |

| Wuxia | 武侠 | 霧の竹林や砂漠を舞台に、重さを感じさせない空中の剣劇。衣装と霧の色 | `Wuxia style。霧の立ち込める竹林の梢を、白い衣の剣士が重さを感じさせず飛び移る。` |

| Heroic Bloodshed | 香港アクション／英雄片 | スローモーションの銃撃戦、翻るロングコート、ネオンの夜、義理と友情の物語 | `Hong Kong heroic action。ネオンの反射する夜の倉庫、ロングコートを翻した男が両手に拳銃を構え、スローモーションで横へ跳ぶ。` |
| J-Horror | Jホラー | 湿った日常の室内、青白く彩度の低い画、顔の見えない人物、ゆっくり近づく静けさ | `J-horror style。青白く彩度の低い団地の廊下、蛍光灯が一本だけ明滅し、奥に長い黒髪で顔の見えない人影が立っている。` |

| Bollywood Masala | ボリウッド・マサラ | 鮮やかな衣装の群舞、祝祭の色彩、劇的なズーム、物語から歌と踊りへの突然の切り替え | `Bollywood masala style。黄色とマゼンタの衣装の群舞が広場を埋め、色粉が舞う中、主役の2人が正面のフルショットで踊る。` |

## 3. 記録・現実感

| 技法 | 日本語・別名 | 画面で起きること・向く場面 | 記述例 |
|---|---|---|---|
| Documentary | ドキュメンタリー | 混ざった色温度、窓明かりのインタビュー、目の高さ、手持ちの観察 | `Documentary style。窓明かりのインタビューで画面外の聞き手を見て話す人物、手持ちで職場の様子を観察する。` |
| Found Footage | ファウンドフッテージ | 発見された記録映像という体裁。家庭用ビデオや携帯電話の画質、自動露出の揺れ、ピントの迷い | `Found footage style。家庭用ビデオカメラの粗い画質、自動露出が明滅し、ピントが迷い、撮影者の荒い息が聞こえる。` |
| Mockumentary | モキュメンタリー | ドキュメンタリーの体裁をとった作り話。カメラを見て話すインタビュー、反応を捉える素早いズーム | `Mockumentary style。オフィスの会議室で、社員がカメラをちらりと見て気まずそうに笑う。手持ちのズームで隣の同僚の反応へ寄る。` |
| Mumblecore | マンブルコア | 低予算の自然主義。狭いアパート、その場の光、即興のような会話、手持ちの寄り | `Mumblecore style。散らかった狭いアパートの台所、窓からの自然光だけ、手持ちの寄りで2人のぎこちない会話を捉える。` |

| BTS | メイキング／舞台裏 | 撮影機材やスタッフが画面に入り、作り物の世界の裏側を見せる | `Behind-the-scenes look。照明スタンドとカメラクルーが画面の端に見え、セットの中で演技する俳優を横から捉える。` |

| Stylistic Suck | わざと下手な映像 | 迷うズーム、安いビデオ画質、ずれたホワイトバランスをあえて選ぶ | `Deliberately amateur look。ズームが行き過ぎては戻り、ホワイトバランスが青く転んだ安いビデオ画質。` |
