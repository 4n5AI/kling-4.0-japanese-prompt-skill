# Kling 4.0 プロンプト記法ガイド

Kling 4.0 に固有の書き方（2つの制作入口、書き方の原則、公式のプロンプト構成、時間とショット、全能リファレンスの `@` タグ、キーフレーム、動画編集、セリフと音声、画面の文字と字幕、否定表現、スタイル）をまとめる。中心となる根拠は **Kling 4.0 公式ユーザーガイド**（2026-10-15公開）。カメラの動きは [camera-movements.md](camera-movements.md)、レンズと被写界深度は [lens-and-focus.md](lens-and-focus.md)、ショットサイズ・アングル・構図は [shot-composition.md](shot-composition.md)、光と色は [lighting-color.md](lighting-color.md)、複数ショットの連続性は [multi-shot-continuity.md](multi-shot-continuity.md) を参照する。数値条件の一覧と出典は [source-guide.md](source-guide.md) にある。

**確度の表記**：各項目に確度を付ける。

- **【公式】** Kling公式ページで本文を確認したもの。主な根拠は Kling 4.0 公式ユーザーガイドとリリースノート（[source-guide.md](source-guide.md) の §1）。kling.ai の 3.0／3.0 Omni／O1 のガイド・公式ブログに由来する項目には**「（3.0時点）」「（O1時点）」のように世代を添える。** 4.0のガイドと食い違う場合は4.0のガイドを優先する。
- **【第三者】** 公式情報を解説する第三者記事などで、複数の独立した情報源が一致するもの。公式の一次文面は未確認。
- **【未確認】** 情報源が単一、または裏付けが弱いもの。このSkillの提案（目安）もここに含める。ユーザーへ断定して伝えない。

**【第三者】【未確認】の項目をユーザーへ説明するときは、公式で未確認であることを添える。数値や仕様を発明しない。** 4.0のガイド自体も「機能やパラメータの詳細は実際の製品ページを確認する」としているので、画面の表示を最終的な基準にする。

## 1. モデル・入口・世代の取り違えに注意（最重要）

### 2つの制作入口（**【公式】**）

Kling 4.0 の制作ツールには、上位の入口として**「全能リファレンス」（Omni Reference）**と**「キーフレーム」（Keyframes）**の2つがある。**現時点では、2つの入口の機能を1回の生成タスクで併用できない。**

| 比較項目 | 全能リファレンス | キーフレーム |
|---|---|---|
| 適した用途 | 参照したい画像・動画素材がある、またはアイデアの方向性だけが決まっている | 画面の節目が決まっていて、各フレームを完成動画で再現したい |
| 制御する対象 | 映像の外観、スタイル、動き、カメラワーク | タイムライン上の各節目 |
| アップロードできる素材 | 画像、動画、音色 | 画像のみ（参照素材は不可） |

- **全能リファレンスが既定の入口**で、最も幅広い機能を使える。テキストから動画、キーフレームからの動画生成もこの入口から実行できる。
- **キーフレームの入口**は、従来の画像から動画（開始フレーム／始終フレーム）の操作に慣れた人向けで、**キーフレームの画面をピクセルレベルで維持したい**場合に適する。
- 使い分け：具体的な参照素材がある、またはアイデアから自由に試す → 全能リファレンス。特定の時点の画面を固定したい → キーフレーム。

### 4.0 と 4.0 Flash（**【公式】**）

| 項目 | Kling 4.0 | Kling 4.0 Flash |
|---|---|---|
| 尺 | **3〜30秒**（1秒単位、既定10秒） | **最長20秒**（仕様表では3〜20秒） |
| 解像度 | **720p／1080p／4K** | **最大720p**（8bit SDR） |
| 始終フレーム・複数キーフレーム | 対応（キーフレーム最大10枚） | **非対応**（開始フレームからの画像→動画は対応） |
| 全能リファレンス | 対応 | 対応 |
| 向く用途 | 長い動画、高解像度、画面の節目の制御 | アイデアを頻繁に試す、短い動画、生成時間とコストを抑える |

- **Flash で使う場合は20秒以内・720pに収め、始終フレームやキーフレームを前提にしない。** 必要なら4.0を使うよう案内する。

### 世代の違い

Web上には Kling 1.x〜3.0 向けの助言が多く残っている。**4.0 の条件で書き、古い世代の尺やモードの助言を当てはめない。**

| 項目 | 1.x〜2.x 時代 | 3.0／3.0 Omni（3.0時点） | **Kling 4.0** |
|---|---|---|---|
| 尺 | 5秒か10秒 | 3〜15秒 | **3〜30秒** |
| ショットの分割 | 単一ショット | Multi-Shot／Custom Multi-Shot のスイッチ | **スマート絵コンテが常に有効**（切り替えなし。§4） |
| 参照素材 | Elements | 画像最大7、動画1本 | **合計15点まで**（§5） |
| 終了フレームだけの指定 | — | 非対応（O1時点） | **対応**（§6） |
| 音声 | リップシンクは別機能 | ネイティブ音声、5言語 | **ステレオ、9言語以上と方言・アクセント**（§8） |

- 旧ガイドの「5〜10秒で完結する簡単な内容にする」は旧世代の条件。**4.0の尺の設計には使わない。**
- 3.0 の Multi-Shot／Custom Multi-Shot のスイッチを前提にしない。4.0 のガイドでは、ショットの自動分割（スマート絵コンテ）と音声・映像の同期は**既定で有効で、オン・オフの切り替えがない**。
- **他モデル向けの括弧記法（`( )` で音楽、`< >` で効果音、`{ }` でセリフを書き分ける書式など）を持ち込まない。** Kling の公式の構成テンプレートは `【素材の役割】` のように**見出しとして**角括弧を使う（§3）。セリフは引用符で書く（§8）。

## 2. 書き方の基本原則（**【公式】**）

**具体的な描写を使い、抽象的な表現や否定表現を減らす。** 画面の特徴をできるだけ具体的に書くと、モデルの推測が減る。否定表現を含むプロンプトは、生成結果が不安定になることがある。

| おすすめしない | おすすめ（公式の例） |
|---|---|
| 「高級感のある質感」 | 斜め後方からの光が物体の輪郭を際立たせ、背景はぼけている。表面には細かなマット加工の粒子が見える。 |
| 「年代を感じさせる雰囲気」 | 壁は黄ばんでおり、家具の角には擦れがある。暖色の白熱灯が照らしている。 |
| 「中流家庭のキッチン」 | 木目調のキャビネット、カウンターの炊飯器と調味料入れ、冷蔵庫の扉に貼られた付箋。 |
| 「被写体の正面を見せず、電話をしている」 | （見せたい状態を直接書く）被写体の横顔、電話をしている。 |

- **否定表現として本当に書くべきなのは「字幕なし」「BGMなし」の2つだけ。** モデルが既定で字幕やBGMを付けることがあるので、不要なら明示的に除外する（§10）。
- **短い指示でもよい。** 被写体と、何をさせたいかを書けば、モデルがストーリー、場面の動き、カメラワークを補って展開する（公式の例：`An old man ranting about AI.`）。**指示が十分に具体的なら、余計なアレンジを加えず忠実に生成する。** 方向性を探る段階や試作は短く、固定したい要素があるときは具体的に書く。
- **長ければよいわけではない。** まず**被写体・場面・動作・感情を一文で**明確にし、そのうえで結果に本当に影響する**カメラワーク・時間の流れ・音声・維持したい条件**だけを足す。形容詞を並べるより効果的。
- 入力できる長さは**最大8,000トークン**。
- **個数は明記して固定する。** 公式の詳細な作例は「`EXACTLY 1 DRAGON — NO DUPLICATES`」「Shot 1 contains exactly one apple」のように、登場する数をはっきり書いている。
- 動きは見える変化で書く。跳躍・落下・衝突などは、踏み切り → 空中 → 着地 → 接地のように段階と重さ・慣性を書く（公式の作例は「慣性で尾が遅れて振れる」「着地の重さと衝撃を伴う」のように物理を書く）。
- 結果が期待と違うときは、まず**①各素材に役割が明記されているか、②「高級感」「映画のような雰囲気」のような抽象語が残っていないか**を確認し、光の当たり方・素材の質感・構図の具体的な描写へ置き換える。

## 3. プロンプトの構成（**【公式】**）

### 基本テンプレート

4.0 の公式ガイドが示す構成。

```text
【素材の役割】
@画像1は___の参考とし、___の一貫性を保つ。
@画像2は___の参考とし、___の一貫性を保つ。
@動画1の___を参考にする。
【全体設定】
シーンと質感___、ビジュアルスタイル___、カメラの基調___。
【シーンごとの展開】
0～X秒：___（画面＋動作＋感情）
X～Y秒：___（カメラの動き＋詳細）
Y秒～終了：___（最後の画面）
【音声】
セリフ／ナレーション＋環境音＋BGM＋効果音
```

- 素材を使わない場合は `【素材の役割】` を省く。
- 複数人物・車両などが出る長い作例では、`【全体のスタイル】` `【人物と車両】` `【ショットと動作】` のように、登場要素の詳細を独立した見出しにまとめている。

### 詳細版テンプレート（公式の長尺作例の構成）

公式ガイドの30秒・15秒の詳細な作例は、次の見出し構成で書かれている（英語の作例が多いが、日本語の作例も同じ構成をとる）。複雑な広告・アクション・複数ショットで、制御を最大にしたいときに使う。

| 見出し | 書く内容 |
|---|---|
| `SCENE CONTEXT` | 一文の要約、尺、ショット数、登場する数の固定（`EXACTLY 1 ... — NO DUPLICATES`） |
| `ACTIVE REFERENCES` | 各 `@` 素材が何を制御するか、何を引き継がないか |
| `LOCATION MAP` | 空間の配置（画面の左右・奥）、移動方向の軸、カメラが軸のどちら側にいるか |
| `FIRST FRAME AND SPATIAL BLOCKING` | 最初のフレームの状態と人物・物の配置 |
| `FORMAT MODE` | 縦横比、尺、ショット数、カットの種類と位置（`hard cuts at 3.0, 5.0 ...`）、使わないトランジション |
| `OPTICS` | ショットごとの焦点距離と水平画角、見え方（`24mm, 74° horizontal FOV, low-angle environmental wide`）、被写界深度 |
| `CAMERA` | 撮影者の動き（手持ちの揺れ、距離、高さ）、ショットごとの移動 |
| `ACTION TIMING` | 秒単位の動作の割り付け（`0.0–2.0s: ...`） |
| `PHYSICS` | 重さ、慣性、接触、布や髪の遅れ |
| `LIGHTING` | 動機のある光源の方向と色、ハイライトとシャドウの保持 |
| `AUDIO` | セリフ（話し方、強調する語）、環境音、効果音、音楽の有無とミックス |
| `CHARACTER ACTING` | 表情・視線・感情の変化、心の声（`INNER, UNSPOKEN: ...`） |
| `STYLE` | ルック、質感、色の配分（`60:30:10`） |
| `QUALITY` | 一貫させる要素（身元、形状、文字の綴り）、破綻させない要素 |
| `POSITIVE CONSTRAINTS` | 守らせる条件を肯定文で列挙（「〜は1人だけ」「ロゴは正面で見える」） |

- 見出しの名前は日本語でもよい（公式の日本語の作例は「SCENE CONTEXT — ...」「カメラと光学表現：」のように併記している）。
- 全項目を毎回書く必要はない。基本テンプレートで足りる依頼に、詳細版を押しつけない。

### 作例に見られるそのほかの見出しと書き方（**【公式】**）

- **音声を細かく制御する作例**は、`AUDIO` を `VOICEOVER`（ナレーションの声質と各行の開始秒）／`MUSIC`／`SFX`／`AMBIENCE`／`MIX`（音量の優先順位）／`SUBTITLES` に分けて書く（§8）。
- **短めの作例**（15秒のクレイアニメ）は、`尺`／`アスペクト比`／`カメラ`／`ビジュアルスタイル`／`ビジュアルコンセプト`（作品の核を一言で：「空腹と勇気」）／`環境`／`音声`／`感情の流れ`／`ストーリーボードのビート` の見出しで書く。
- **感情の流れを強さの段階で書く**：`L1 好奇心 → L3 驚き → L4 恐怖 → L5 追跡劇のクライマックス → L1 温かく満ち足りた幸福感`。形容詞を並べるより、山と谷の位置が伝わる。
- **絵コンテのコマ番号を区間に添える**：`0～2秒（P01）：…`。絵コンテの画像を参照するとき、コマと区間を一対一で対応させる。
- **失敗の条件を1文にまとめる**：英語の作例は `POSITIVE CONSTRAINTS` の最後に「平板で感情のない話し方、さまよう視線、崩れたロゴ、変わる着丈、余分な手足 … = failed shot」のように、失敗とみなす状態を列挙している。本文に否定文を散らす代わりに、意図の核心を外す状態だけを末尾の1文に絞る（§10）。

この節の書き方を依頼に足すのは、詳細版テンプレートを使う複雑な依頼に限る。短いプロンプトには持ち込まない。

## 4. 時間とショット構成

### スマート絵コンテ（**【公式】**）

- **スマート絵コンテ（Smart Storyboard）は既定で有効で、オン・オフの切り替えがない。** モデルが内容に応じてショットを自動的に分割し、テンポを組み立てる。
- そのため、**カットの数と位置を決めたいとき、またはカットを入れたくないときは、プロンプトに明記する。** 書かなければ、モデルがショットを分けることがある。

### 時間の書き方（**【公式】**の作例に見られる書式）

| 書式 | 例 |
|---|---|
| 区間＋内容（基本テンプレート） | `0～3秒：...` `3～7秒：...` `Y秒～終了：...` |
| タイムコード＋見出し | `00:00～00:03｜カーチェイス、5ショットの高速カット` |
| 英語の区間 | `0.0–3.0s — THE MILITIA MARCHES：...` |
| ショット番号＋区間 | `SHOT 1 — 0.0–4.0s: roar and launch.` |
| キーフレームの区間 | `0.0～2.1秒｜キーフレーム1：...`（§6） |
| 長回しの中の時点 | `At the 4th second, ...` `4秒目で ...`（3.0時点の作例） |

- **小数の秒も使える。** 公式の作例は `4.5～7秒`、`2.1～4.3秒`、字幕では `0.78–1.38秒` のように、音や動作に合わせて小数で区切っている。
- 区間は**隙間なく連続させ、最後の区間を全体の尺で終える**（`Y秒～終了` でもよい）。1つのプロンプト内で書式を混在させない。
- このSkillの既定は、基本テンプレートの **`0～4秒：`** の形式。ショットを分けるときは区間の冒頭にショットサイズを書き、カットの種類を `【全体設定】` か区間内に書く。

### ショットを分ける

- ショット数とカットの位置を明記する：`15秒、5ショット、クリーンなハードカットでつなぐ`、`Hard cuts at 3.0, 5.0, 8.0, 10.0, and 11.0 seconds.`
- 使わないトランジションも書く：`No fades, dissolves or split screens.`
- **カットに動機を持たせる**（公式の作例）：翼や煙が画面を横切る遮蔽（wipe）、手前の物体の通過、動作の頂点、音の頭（「音をカットより0.1秒早く入れる」）に合わせる。
- 公式の作例には、3秒の中に5ショットの高速カットを入れる例もある。短いショットを並べるときは「最初の4ショットは短く、最後は少し長く」のように配分を書く。
- **1ショット＝1主要アクション＋主要カメラ移動1つ**（多くても方向が矛盾しない2つまで）。
- **セリフは、話者が画面に映っている間に言い切らせる**（公式の作例：「監督が画面に映っている間に、セリフを最後まで言い切る」）。
- **各ショットを動作の途中から始める**（公式の作例：`Every shot begins mid-gesture with the teacher already pointing toward the active numeral. No empty establishing beat.`）。短い尺では、何も起きない導入の数秒を作らない。
- **省略はカットで行い、動作は自然な速さのまま書く**（公式の作例：鍛冶の工程を6ショットに分け、`Manufacturing time is compressed through editorial cuts; individual actions retain natural weight and speed.`）。長い工程を早回しにせず、節目の動作だけを見せる。
- **カットをまたいで固定する条件を書く**（公式の作例）：レンズ（`35mm equivalent, 54° horizontal FOV, locked across all five shots`）、カメラの高さと距離（「約105cm」「3.0〜3.3m」）、撮影軸のどちら側か、光源の方向・色温度・霞の濃さ・露出、音楽と環境音（カットで途切れさせない）。ショットごとに変えるのは、変える理由がある要素だけにする（[multi-shot-continuity.md](multi-shot-continuity.md)）。

### ワンカット（長回し）

- スマート絵コンテが常に有効なので、**ワンカットにしたいときは必ず明記する。** 公式の作例の書き方：
  - `全編を通して、目に見えるカットのない連続したワンショットとする。`
  - `映像全体を…連続したサイドトラッキングの長回しで構成する。ワンカットで撮影し、カット割り、アングル変更、シーン変更は一切行わない。`
  - `One uninterrupted 15-second vertical 9:16 shot. No cuts, fades, dissolves, speed ramps ...`
  - `N秒間のワンカット。`（リリースノートの作例）
- ショットサイズを変えたいときは、**連続したカメラ移動で変える**と書く（公式の作例：「すべてのショットサイズの変化は、この連続したカメラ移動によって実現する」）。
- 1つの進化する運動として書く。始まりと終わりのある弧を描き、無関係な動作を積み重ねない。
- **ワンカットの中の出来事として遮蔽を書く**（公式の30秒の作例）：「黄色いタクシー、または歩行者の集団がカメラと女性の間を素早く横切り、約0.5～1秒間、画面全体を完全に遮る」。遮蔽の後に起きること（人物が画面中央から外れている → カメラが減速して探す → 再び捉える）まで書くと、カットを入れずに展開を変えられる。
- 人が操作しているような不完全さも書ける（公式の作例）：「軽いピントの行き過ぎ、引き戻し、一時的なピンぼけ」「加速・減速時の慣性。ただし、激しい手ブレは避ける」。

## 5. 全能リファレンス（参照素材）と `@` タグ

### 入力制限とパラメータ（**【公式】**）

| 入力 | 上限・仕様 |
|---|---|
| テキスト | 最大8,000トークン |
| 画像 | 合計10枚以下。1枚30MB以下。縦横比 2:5〜5:2 |
| 動画 | 合計5本以下。1本3〜30秒、合計30秒以下。1本300MB以下。縦横比 2:5〜5:2 |
| 音色（ボイスプロファイル） | 1回あたり最大3種類。作成用の音声は5〜30秒、50MB以下 |
| 被写体（Element） | 合計7体以下。うち動画の被写体は3体以下。動画の被写体の作成素材は3〜8秒 |
| 合計 | 画像・動画・音色・被写体を合わせて最大15点 |

| パラメータ | 選択肢 |
|---|---|
| 生成モード | 720p／1080p／4K |
| 長さ | 3〜30秒、1秒単位。既定は10秒 |
| 縦横比 | 21:9／16:9／1:1／9:16／自動。既定は自動 |

- **参照動画・編集用の動画・動画の被写体は、動画の入力上限を共有する**（合計5本、総時間30秒以内）。参照動画を5本入れた後に動画の被写体は追加できない。
- **BGMや効果音はアップロードできない。** 音声の入力は話者の音色を指定する音色リファレンスのみ。BGMと効果音はモデルが映像に合わせて生成するので、プロンプトの音声の項目に書く。
- 素材が多い場合は、映像やテンポに最も影響する素材を優先する。上限まで使うことを推奨しない。

### `@` タグ（**【公式】**）

- 素材には**アップロード順に自動で番号が付く**。日本語の画面では `@画像1`・`@画像2`・`@動画1`・`@被写体1`、英語の画面では `@Image1`・`@Video1`・`@Element1` と表示される。**画面に表示された番号をそのまま使う。**
- **各素材の用途を明確に指定する。** 番号だけを書いて役割を説明しないと、モデルが用途を推測するため、結果を制御しにくくなる。
- **複数の素材がそれぞれ別の情報を提供する場合は、各素材の役割と適用範囲を個別に書き、取り入れたくない要素も明確にする。**
- 素材が多いときは、各 `@` 番号が正しい素材を指しているかを確認する。

公式の例：

```text
@画像1はこのシーンの参考とし、空間構成、配置、照明を維持する。
@画像2はヒロインの参考とし、顔立ち、髪型、衣装を維持する。
ヒロインはこのシーンの中で窓辺まで歩き、立ち止まって振り返る。
```

- 引き継がない要素を書く例（公式の作例）：「`@Video1`: 内容、ナレーション、タイミングの参照のみ。白いスタジオの環境や見た目のスタイルは引き継がない」「`@Image1`: 世界観の参照のみ。既存のキャラクター、数字、構図は引き継がない」。
- **再登場点でアイデンティティを再宣言する。** ショットが変わって人物が再び映るとき、`@` 番号と識別特徴（年齢・髪型・服）を短く再掲する。人物が多いほど必要。
- 実際にアップロードされる素材の番号・順序に合わせる。**未提供の素材を存在するものとして書かない。**
- API では `@image_1`・`@video_1` の形式や、サービスによって `<<<image_1>>>` の形式があるとされる（**【第三者】**）。利用するサービスの記法に合わせる。

### 参照の種類と書き方（**【公式】**）

人物の外見、動作、カメラワーク、空間関係、音色などを別々の素材から参照し、1回の生成で組み合わせられる。重要なのは、**各素材が何を提供し、最終的にどんな映像にしたいか**を伝えること。

| 参照する要素 | 公式の例 |
|---|---|
| 複数キャラクター・物 | `@画像1、@画像2、@画像3の人物の顔立ちと特徴を参照し、厳密に維持する。@画像4の青いバイクのデザインを参照し、厳密に維持する。` |
| 動作 | `@動画1の格闘動作と技を繰り出すテンポを参考にする。キャラクターのデザインは@画像1、@画像2を参照する。` |
| カメラワーク | `@動画1のカメラの移動軌跡とショットのテンポを参考にする。被写体を@画像1の車に置き換え、背景を@画像2に置き換える。` |
| 構図 | `@画像1の構図を参照し、厳密に維持する。` |
| 絵コンテ | `@画像2の絵コンテは、ショット順、フレーミング、カメラの移動経路、画面の向き、感情の高まりを示すものとする。` に加え、**絵コンテそのものを映像として描写しない**（鉛筆スケッチの質感、グリッド、タイトル欄、注釈、指示欄は入れない）と書く |

- 画像の参照には、被写体画像、三面図、グリッド画像、インフォグラフィック、キーフレーム、ワイヤーフレームなどの形式を使え、見た目・シーン構成・映像スタイル・文字やグラフィック要素・カメラ構図・重要な展開まで指定できる（**【公式】**、リリースノート）。
- 動画の参照は、キャラクターの演技や動作、カメラワーク、ストーリーのテンポを再現でき、**ホワイトモデル（白い3Dモデル）の動画やデプスマップ（深度）の動画**にも対応する（**【公式】**、リリースノート）。動きや配置の参照であり、最終的な見た目は被写体や画像で定義する。

### 被写体（Element）と音色

- 4.0：被写体は合計7体以下（動画の被写体は3体以下、作成素材は3〜8秒）。音色は1回3種類まで、作成用の音声は5〜30秒（**【公式】**）。
- 3.0時点の作り方：複数画像の被写体は2〜4枚（正面のメイン1枚＋別角度1〜3枚、正面を推奨）。音声は雑音・重なった声・大きな音楽がないものを使う（**【公式】**、3.0時点）。
- **声を紐づけた被写体は、プロンプトで声色を再指定しない**（**【公式】**、3.0時点）。話し方・感情だけを書く。

## 6. キーフレーム

### 入力制限とパラメータ（**【公式】**）

| 項目 | 内容 |
|---|---|
| テキスト | 最大8,000トークン |
| 画像 | 合計10枚以下。1枚30MB以下。縦横比 2:5〜5:2 |
| 生成モード | 720p／1080p／4K |
| 長さ | 3〜30秒、1秒単位。既定は10秒 |
| 縦横比 | 画像なしなら 21:9／16:9／1:1／9:16 から選ぶ。画像をアップロードした場合は**最初のキーフレームの縦横比に従う** |

- **キーフレームの入口では参照素材（動画・音色・被写体）をアップロードできない。**
- キーフレームを使わない場合、画面が変わる順番とタイミングはモデルが決める。キーフレームを使うと、指定した時点の画面をユーザーが定義できる。
- 4.0 は**開始フレーム、終了フレーム、始終フレーム、任意の位置の中間フレーム**に対応する。

### 制御できること（**【公式】**）

| 制御する要素 | 例 |
|---|---|
| キャラクターの動作 | 3秒目に手を上げ、7秒目に振り返る |
| 登場・退場 | キャラクターBが最後ではなく、6秒目にドアから入ってくる |
| シーンの変化 | 5秒目に空が暗くなり、10秒目に雨が降り始める |
| 構図の変化 | 指定した秒数でロングショットからクローズアップに切り替える |
| 状態の変化 | 状態Aから状態Bへ移る過程と、途中の節目を指定する |

### 書き方（**【公式】**）

| 種類 | 書き方 |
|---|---|
| 開始フレーム | `@画像1を開始フレームに設定し、［その後に起こること］を記述する。` |
| 始終フレーム | `@画像1を開始フレーム、@画像2を終了フレームに設定し、その間の［過程］を生成する。` |
| 終了フレーム | `@画像1を終了フレームに設定し、［それ以前に起こること］を記述する。` |
| 中間フレーム | `X～Y秒｜キーフレーム1：［何が起こるか］ Y～Z秒｜キーフレーム2：［何が起こるか］ …` |

- 公式の中間フレームの作例は、画像を `@画像1` ではなく「画像ノード_23に厳密に合わせる」のように**画面上のノード名**で呼んでいる（命名の説明はガイドにない）。`@` 番号でもノード名でも、**利用画面に表示されている呼び名をそのまま使う。**
- **中間フレーム**では、各キーフレームに**その時点の画面内容と、カメラがどのようにその位置へ到達するか**を書く。絵コンテが決まっていて、各重要画面をタイムライン上に正確に反映したいときに向く。
- 公式の中間フレームの作例は、区間ごとに「キーフレームの画像に厳密に合わせる」「カメラは固定」「約3%ゆっくり寄せる」と書き、**カットの合図**（動作の頂点、音、遮蔽、靴先の動き）と、**してはいけない変化**（姿勢を変えない、物の位置を変えない）を添えている。
- 始終フレームが向く場面：変化の過程、製造工程、ビフォーアフター（**【公式】**）。終了フレームの作例では、実写から名画の構図へ徐々に変化させ、最終フレームで原画と一致させている。
- 開始フレームと参照動画を組み合わせる公式の作例（`@Image1 is the first frame. @Video1 is the reference for camera, motion, timing and cuts. Recreate @Video1 shot-for-shot and cut-for-cut, but starting from @Image1: ...`）もある。参照動画を使う場合は、キーフレームの入口ではなく全能リファレンスの入口で作る（キーフレームの入口は参照素材を受け付けない）。
- 始終フレームの英語の作例から読み取れる書き方（**【公式】**）：
  - 開始フレームを**動作の始まりの状態**として宣言する（`This image is the starting state of an active pickup shot.`）。止まった絵から始めず、0.6秒以内に手が入るなど、すぐに動き出す。
  - 終了フレームへは**目に見える動作で到達させる**（`This composition is reached through a visible physical placement.`）。手で置く、歩いて止まるなど、最後の構図に収まる原因を書く。
  - 物が登場する前に、空の状態を短く見せる（「空のテーブルを0.4秒見せてから剣が入ってくる」）。
  - キーフレームの画面と、推定のレンズ・距離の数値が食い違うときは、**画面を優先させる**（`Exact endpoint framing takes priority over estimated optical measurements.`）。
  - 最後の区間で止める画面を書く（「この画面を維持する」「照明をゆっくり弱め、均一に暗がりへ沈める。色温度を変えない」）。
- 隣り合うキーフレームは同じテーマ・似た構図にすると、意図しないカットが入りにくい（**【公式】**、旧ガイドの始終フレームの助言）。大きく変える区間では、変化の原因（振り向く、扉を開ける、カメラが回り込む）を書く。

## 7. 動画編集・人気動画の再現

### 編集の必須ルール（**【公式】**）

- **プロンプトに「@動画1を編集」（`Edit @Video1`）と明記し、変更対象と変更内容を具体的に書く。**
- **ほかの部分を維持したい場合は「その他は変更しない」（`Keep everything else unchanged.`）と書く。** 維持する範囲を書かないと、ほかの映像要素も変わることがある。
- 「@動画1を参考にする」とだけ書くと、**参照生成として扱われる**ことがある。

| 目的 | 適切な書き方 | 不適切な書き方 |
|---|---|---|
| 動画そのものを変更する | `@動画1を編集し、……を……に変更する` | 「@動画1を参考にする」と書き、「@動画1を編集する」と明記しない |

- 入力条件：動画は最大5本（うち1本をメイン動画として使う）、各3〜30秒、合計30秒以下。参照画像との併用を推奨（**【公式】**、仕様表）。
- 変更できるもの：キャラクターの表情や動作、カメラ位置やカメラワーク、全体のスタイル、背景、被写体の追加・置き換え・削除、天候、色味、質感、ショットサイズ、視点など（**【公式】**）。

### 公式の例

| 変更する要素 | 書き方 |
|---|---|
| 被写体の追加 | `@動画1を編集する。最後に箱が再び開く場面で、@被写体1が箱の中で横になって眠っている状態を追加する。` |
| セリフの変更 | `最後のセリフ「Ah, it's all old stuff.」を「Why is there a pig here?」に変更する。` |
| 人物とシーンの置き換え | `@動画1を編集し、動画内の環境と人物を全体的に@画像1の内容に置き換える。` |
| 複数キャラクターの置き換え | `@動画1を編集し、コンビニの入口から順番に出てくる3人を、それぞれ次の人物に置き換える。1人目：@画像1＋「新しい被写体の外見」。2人目：…` |
| 要素の削除 | `@動画1の前景にいる人物を削除し、その他は変更しない。` |
| スタイルの変更 | `@動画1を編集し、動画内のコーギーを3Dピクセルアート風のコーギーに置き換える。動作は維持する。` |

詳細な作例から読み取れる書き方。

- 置き換えでは、新しい人物の**身元・顔・髪・服装・持ち物**を具体的に書き、登場順・動作・カメラワーク・テンポは「@動画1の動作とカメラワークを参考にする」と書く。
- 削除では、**隠れていた部分を自然に補完し、痕跡を残さない**と書き、維持するもの（背景、ほかの被写体、カメラワーク、照明、構図、尺）を列挙する。
- スタイル変更では、**変えるのは対象だけ**と書き（「ブロック風に変えるのはコーギーだけ。周囲は実写のまま」）、大きさ・位置・動作・軌跡を元の各フレームに合わせ、**音声は元の動画と完全に一致させ、新しい音を足さない**と書く。
- セリフを変える場合は、新しいセリフにリップシンクの3規則（日本語の場合）を適用する。

### 人気動画の再現（**【公式】**）

気に入った参考動画のストーリーのテンポ、ショット構成、見せ方を参考にしながら、キャラクター・商品・シーンを置き換えられる。**参考にする部分と置き換える部分を明確に書く。**

```text
@動画1の被写体を@画像1に置き換え、その他は変更しない。
```

- 参考動画と作りたい内容の**テンポ・ショット構成・カメラワークが近いほど**、期待する結果を得やすい。
- 英語の作例では、維持するもの（背景の構図、カメラワーク、照明、影、音声、尺）を列挙し、置き換えた被写体を元の映像に自然になじませるよう書いている。

### 旧世代の構文（O1時点）

O1 の公式ガイドには、4.0 のガイドにない操作の構文もある（**【公式】**、O1時点。4.0 での動作は画面で確認する）。

- 次のショット：`Based on @Video1, generate the next shot: [ショットの内容]`
- 前のショット：`Based on @Video1, generate the previous shot: [ショットの内容]`
- グリーンバック：`Change the background in @Video1 to a green screen, and keep [残す内容]`

### 延長

- アップロードした動画を複数回延長し、**最長2分まで**つなげられる。公式ガイドの表記は**「近日公開予定」**（**【公式】**）。提供状況は画面で確認する。
- 旧ガイドの「延長のプロンプト＝主体＋動き」「元動画と無関係な文はカットや転換を招く」という助言は引き継いでよい（**【公式】**、旧ガイド）。元の末尾の人物・物体・移動方向から続け、連続撮影か場面転換かを明記する。

## 8. 音声・セリフ・言語

### 対応範囲（**【公式】**）

- 音声はステレオ。リップシンクの精度が向上し、音声・セリフ・演技が自然に同期する。音声と映像の同期は既定で有効で、切り替えはない。

| 項目 | 対応範囲 |
|---|---|
| 言語 | 中国語、英語、日本語、韓国語、スペイン語、ポルトガル語、ドイツ語、フランス語、ヒンディー語 |
| 中国語の方言 | 四川方言、広東語 |
| 中国語のアクセント | 北京、東北地方、台湾 |
| 英語のアクセント | アメリカ英語、イギリス英語、インド英語 |

### 書き方（**【公式】**）

- **特定の言語で話させたいときは、引用符内のセリフをその言語で直接書く。**
  - 例：`スペイン人女性の観光客が…自然で明瞭な、ややゆっくりとしたスペイン語で話す。「¿Dónde está la estación de metro más cercana?」`
- **声をより具体的にしたいときは、話者の年齢、声質、話す速さ、感情を足す。** 強調する語も指定できる。
  - 例：`誠実で感情のこもった英語で話す。「…」冒頭は温かみのある好意を込め、「love」と「confident」を強調する。`
- 複数の話者がいる公式の作例は、`シーン設定`／`ストーリーとセリフ`（区間ごとに誰が何語で何を言うか）／`音声要件`／`カメラワーク`／`映像スタイル` の見出しで書き、音声要件に次を入れている。
  - 話者ごとに使う言語を限定する（「スペイン人観光客はスペイン語のみを話す」）
  - 声質をそれぞれ明確に区別する
  - **一人が話している間、ほかの人は静かに聞き、セリフを重ねない**
  - 話し終えてから約0.5秒の間を置く
  - 口の動きを対応する言語に正確に同期させる。発音は自然で標準的にし、英語なまりにしない
  - 環境音をわずかに残し、BGMは足さず、環境音がセリフをかき消さないようにする
- セリフは、**話者が画面に映っている間に言い切らせる**（§4）。
- BGM・効果音は**アップロードできない**ので、`【音声】` に書く（§5）。
- 3.0時点の公式ブログの助言：話す人物の顔が見えるショットにする。文法を単純にし、長い文は短いセリフに分ける。話し方の注記は場面に必要なときだけ付ける。

### ミックスと音の配置（**【公式】**の作例に見られる書き方）

- **音量の優先順位を書く**：`Music ducks beneath every spoken line.`（セリフの間は音楽を下げる）、`Roar, wings and fire remain louder than the music.`（効果音を音楽より前に出す）、「環境音がセリフをかき消さないようにする」。ナレーションは `clear and centred` と書く。
- **音楽を入れる区間を限定する**：「最後の3秒間に軽快なチューバとウクレレのアンサンブルを流し、それ以外の時間は音楽を使用しない」。全編にBGMを流すのを既定にしない。
- **環境音と音楽をカットで途切れさせない**：`The ambience never resets at the cuts.`、`Music and ambience remain continuous across every hard cut.`。複数ショットでも1つの場面に聞こえる。
- **音の焦点を画面の出来事に合わせて動かす**：「カメラが追いついたら、荒い呼吸・足音・バッグがぶつかる音を音場の中心に置く」「遮蔽の間はタクシーの走行音が覆い隠す」「見失うと呼吸音が遠ざかり、再び捉えると近づく」。
- **効果音を数と動作に同期させる**：「数字が弾むたびに柔らかいポンという音を1回」「ハンマーの3回の打撃に合わせた3つの衝撃音」。
- **楽器と音の素材を具体的に書く**：「古箏と笛の合奏」「マリンバ、トイピアノ、ウクレレ、手拍子」「低音の金管のオスティナート、急き立てる弦、言葉のない低い合唱」。ジャンル名だけで済ませない。
- 音響の技法（環境音、フォーリー、ガヤ、音先行／音残し、無音、ダッキングなど）の語彙は [techniques/sound.md](techniques/sound.md) にある。

### このSkillの書式

公式の書き方（地の文で話者と話し方を書き、続けて引用符でセリフ）に合わせ、短いプロンプトでは話者ラベル形式も使う。

```text
話者ラベル（話し方、言語）：「発話する語だけ」
```

- 例：`研究者（30代女性、落ち着いた低めの声、ゆっくり、日本語）：「2,000時間のけんさんが、ついに実を結びました。」`
- **かぎかっこの中は発話する語だけにする。** 言語・年齢・声質・速さ・感情はかっこの外に置く。
- **リップシンクの3規則（難読漢字→ひらがな／数値→算用数字／英語→カタカナ）は、日本語のセリフのかぎかっこの中に適用する。** 日本語以外の言語で話させるセリフは、その言語の綴りのまま書く。`@` 番号・ファイル名・URL・画面に表示する文字は改変しない。
- **音色を紐づけた被写体や音色リファレンスを使う話者には、声質を書かない**（話し方・感情だけ）。

---

## 9. 画面の文字・字幕（**【公式】**）

- 中国語・英語・日本語・韓国語・スペイン語・ポルトガル語・ドイツ語・フランス語・ヒンディー語などの文字に加え、**絵文字やロゴ**も生成できる。カメラの動き、人物の移動、シーンの切り替えがあっても文字を鮮明かつ安定して表示できる。
- **字幕もプロンプトに直接書ける。** フォントサイズ、配置、表示時間、セリフとの同期の有無も指定すると、意図に沿いやすい。公式の作例の要素：
  - 焼き込みの英語字幕、画面下部中央のタイトルセーフエリア内、下端から10%上
  - 最大1〜2行、パネルの形・色、文字の太さ・色、十分なコントラスト、位置の固定
  - 各字幕を対応するナレーションに合わせて表示・非表示（`0.78–1.38秒：「ONE.」` のように区間ごと）
  - 字幕の綴り・句読点・タイミングを台本と一致させ、サイズ・書体・位置をカットをまたいで同じにする
- 看板などの文字の作例：`ガラス窓の中央に、読みやすく鮮明で安定した大文字の看板「KLING AI OPEN 24 hours」を固定する。文字は常に正しい綴りで表示し、文字化け、変形、点滅を起こさない。看板は窓の内側に固定し、人物を遮らない。`
- **読ませたくない文字は読めない状態として書く**（公式の作例）：「背景の文字や地図上の文字は判読できない程度にぼかし、実在するブランド名、機関名、ロゴ、ウォーターマークは表示しない」。商品・ロゴを見せる広告と、架空の場面を作る依頼とで書き分ける。
- **セリフと画面の文字の区別**：公式の作例はどちらも「」で書く。区別は引用符ではなく、**話す動詞（言う・話す・叫ぶ）と話者**、または**置き場所の名詞（看板・字幕・ラベル）と位置**で行う。画面の文字にはリップシンクの3規則を適用しない。
- 字幕が不要なら「字幕なし」と明記する（§10）。

## 10. 否定表現と除外（**【公式】**）

- **否定表現は減らす。** 否定を含むプロンプトは結果が不安定になることがある。見せたくない状態ではなく、**見せたい状態を直接書く**（「正面を見せず」→「横顔」）。
- **否定として本当に必要なのは「字幕なし」「BGMなし」の2つ。** モデルが既定で付けることがあるので、不要なら明示する。英語の作例では `no subtitles`、`SFX only, no music, no score, no song, no soundtrack` のように書く。
- 公式の詳細な作例には、守らせたい条件を**肯定文の制約**（`POSITIVE CONSTRAINTS`：「女性は1人だけ」「ロゴは正面で見える」）として書くものと、`ネガティブプロンプト` の見出しで禁止事項を並べるものがある。並べる場合も、ユーザーの意図に直接関わるものだけに絞る。英語の作例には、失敗とみなす状態を `... = failed shot` の1文にまとめる形もある（§3）。
- 4.0 のガイドには、本文とは別のネガティブプロンプト欄の説明はない。3.0以前のAPIには別欄があったとされる（**【第三者】**）。4.0では本文に書く。
- **ユーザーが求めていない禁止事項を足さない。**

## 11. スタイル（**【公式】**）

- 映画風、レトロなDV映像、アニメーション、フェルト風、ファンタジー、サイバーパンク、ピクセルアートなど多彩なスタイルに対応し、指定は素材感・光と影・全体の雰囲気にも反映される。
- **アニメーション風を指定するときは、実写風の表現を避けるよう明記する。** そうしないと2つの質感が混ざることがある。
- 英語版のガイドは、スタイルの指定について「肯定的な描写と明示的な除外を組み合わせると、結果が安定する」とも書いている（日本語版にはない一文）。スタイルの中身を肯定文で書いたうえで、混ざってほしくない質感だけを短く除外する（公式の作例：「ブロック風に変えるのはコーギーだけとする。玄関、雪原、柵、森、空は実写のまま維持する」）。
- スタイル変更の例：`@動画1を編集し、動画のスタイルを@画像1のフェルト風スタイルに変更する。元動画の構図、ショット、動作は維持し、スタイルのみを変更する。人物の衣装デザイン、バイクの形状、シーン内の要素、出来事の順序は変更しない。`
- 公式の詳細な作例は、色の配分を比率で書く（`Charcoal and storm blue occupy 60% of the palette, smoke-brown stone 30%, and fire orange 10%.`）。質感は「古い写真の柔らかさ、自然なフィルムグレイン、デジタルシャープネスなし」のように具体的に書く。
- 名前付きのルックは名前に頼らず、光・色・動き・質感の要素へ分解して書く（[techniques/index.md](techniques/index.md)）。

## 12. 公式が例示する語彙と言語

- 4.0 のガイドが挙げるカメラワーク（**【公式】**）：プッシュイン、プルアウト、パン、トラック、追従撮影、周回撮影。ショットサイズの切り替えやトランジションも滑らかになったとされる。
- 4.0 の詳細な作例の光学の書き方（**【公式】**）：ショットごとに**焦点距離＋水平画角＋見え方**（`24mm, 74° horizontal FOV, low-angle environmental wide`、`50mm equivalent lens with a 40° horizontal field of view`）と被写界深度を書く。数値だけを置かず、見え方の言葉を添える（[lens-and-focus.md](lens-and-focus.md)）。多くの作例は水平画角だが、鍛冶の作例は `approximately 63° diagonal field of view` と対角画角で書いている。画角を書くときは**水平か対角かを明記する**（同じ焦点距離でも値が大きく違う）。
- 4.0 の作例のカメラの書き方：撮影者の身体と動きで書く（「手持ち、呼吸による揺れ、わずかなロール、遅れた構図の修正」「胸の高さ、約2.5m、1m未満の時計回りの弧」）。機械的に安定しすぎた動きを避けたいときは `Not a gimbal, slider, tripod lock-off ...` のように書く。
- 手持ちの揺れの量を一語でまとめる書き方もある（**【公式】**の作例）：`All shots use handheld SETTLE: visible breathing sway, slight roll, and small delayed corrections.`、`World register: gentle SETTLE.`。一語に頼らず、続けて揺れの中身を書く。逆に、揺れを強くする作例は「翼の風圧で撮影者が激しく揺さぶられる」「機械的に完璧な動きにしない」のように、揺れの原因を書く。
- 寄りの量を距離で書く（**【公式】**の作例）：`slow 10 cm push toward numeral 1`、「構図を変えずに、カメラを約3％ゆっくりと寄せる」。「少し寄る」より再現しやすい。

3.0時点のガイド・作例に現れる英語の語彙（**【公式】**、3.0時点）。

| 区分 | 語彙 |
|---|---|
| ショット | `extreme close-up`, `close-up`, `medium close-up`, `mid-shot` / `medium shot`, `full body shot`, `wide shot`, `establishing wide shot`, `long shot`, `macro shot`, `profile shot` |
| アングル・視点 | `low angle`, `high angle`, `eye level`, `frontal`, `side view`, `top-down shot`, `bird's-eye view`, `first-person POV`, `over the shoulder` |
| 動き | `push-in` / `dolly-in`, `pull back`, `pan`, `tilt`, `zoom`, `tracking shot`, `follow`, `orbit` / `circles around`, `360-degree pan`, `handheld`, `the camera rises` |
| 構成 | `long take`, `Cut to ...`, `shot-reverse-shot`, `cross-cutting`, `voice-over` |
| 光 | `ambient lighting`, `morning light`, `sunset`, `golden hour`, `rim light`, `Tyndall effect`, `god rays`, `haze` |
| 構図 | `centered`, `rule of thirds`, `off center`, `symmetrical composition` |

### プロンプトの言語

- 4.0 の公式ガイドには、**日本語の短い作例と、英語の詳細な作例の両方**がある（日本語ページでは英語の作例の一部が日本語に訳されている）。どちらの言語でも書ける。
- 日本語の入力でも、複雑なカメラワークやスタイル指定は英語のほうが意図どおりになりやすいとする解説がある（**【第三者】**、主に3.0）。
- このSkillの既定は**「英語の撮影用語＋日本語の演出文」**。詳細版テンプレートの見出しは英語のままでよい。ユーザーが英語を望む場合、または日本語で意図どおりに出ない場合は、**演出文を英語にした版**を出す。どちらの場合も日本語のセリフは日本語のまま（3規則を適用）。

## 13. 避けること

- 「高級感」「映画のような雰囲気」「年代を感じさせる」のような抽象語だけで済ませる（§2の表のように具体化する）。
- 見せたくないことを否定文で並べる（見せたい状態を書く。必要な否定は字幕とBGMだけ）。
- 素材の `@` 番号だけを並べ、役割を書かない。
- 編集なのに「@動画1を編集」と書かない、または維持する範囲を書かない。
- ワンカットにしたいのに明記しない（スマート絵コンテがショットを分けることがある）。
- アニメ調を指定しながら、実写風の表現を避けると書かない。
- 矛盾するカメラ指示の重ね合わせ（`handheld` と `locked steady` を同時に、右へパンした直後に左へホイップパンして急降下、など）。1ショットに無関係な動作を3つ以上積む。
- 品質の語（`4K`、`masterpiece`）を解像度設定の代わりにする。解像度・縦横比・尺は画面で選ぶ。
- 旧世代の尺・モードの助言や、他モデル向けの括弧記法を持ち込む。
